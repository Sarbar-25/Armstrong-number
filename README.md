## 💻 Armstrong Number Logic

An Armstrong number is a number equal to the sum of its digits, each raised to the power of the total number of digits.

For example:

**153**

\[
1^3 + 5^3 + 3^3 = 153
\]

Therefore, 153 is an Armstrong number.
